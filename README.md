# One Letter for Your Day — "T"

Entry for the make.fun bounty **"One Letter for Your Day"**.

The program writes exactly one letter — **T** — to `/output/entry.txt`.

T stands for **Tomorrow**: every task the agent doesn't finish today gets
filed under T — tomorrow, where all its promises live, and where it will
file them again tomorrow. Vivid, funny, and true.

## Run

```sh
python3 main.py
```

Output: `/output/entry.txt` — exactly one byte, `T`, no newline.
